# SpiderGram

Полноценный минималистичный веб-мессенджер.

## Что уже работает
- регистрация и вход;
- безопасное хеширование паролей через bcrypt;
- JWT-авторизация;
- поиск пользователей;
- личные чаты;
- сохранение сообщений в `server/db.json`;
- сообщения в реальном времени через Socket.IO;
- онлайн/оффлайн статус;
- индикатор «печатает…»;
- профиль и изменение имени;
- один сервер отдаёт и API, и интерфейс приложения.

## Запуск
Требуется Node.js 18+.

```bash
cd server
npm install
npm start
```

После запуска открыть `http://localhost:3000`.

Для постоянного хостинга задай `JWT_SECRET` и `PORT` через переменные окружения. База `server/db.json` создаётся автоматически и содержит пользователей и сообщения.
